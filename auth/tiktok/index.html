TikTok authorisation

Connecting your TikTok account

TikTok sends you here after you approve CubeZ. The one-time authorisation code below goes back into CubeZ on your own machine, which exchanges it for an access token. The code is never sent anywhere by this page — it only ever exists in your browser's address bar and on your own computer.

Reading the authorisation code…

Copy that code, return to CubeZ, and paste it at the Paste the code: prompt left open by python -m poster tiktok-login.

Nothing else happens on this page. It has no analytics, no cookies and no server: it is a static page on GitHub Pages that reads the query string your browser already has. See the Privacy Policy.
